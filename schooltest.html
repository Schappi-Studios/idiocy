School network test 🔌

Open this page on a school computer or school wifi. It checks which kinds of addresses the school lets through, so we know where Idiocy's new server can live. It only checks whether each site answers; it doesn't send anything.

✅ = got through. ❌ = couldn't reach it. If a ✅ looks suspicious, tap Open: if you see a Zscaler or "blocked" page instead of the real site, count it as ❌.
